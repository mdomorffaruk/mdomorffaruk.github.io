Installation

Lite (free)

  1. Download simpletube-feed-lite-1.0.0.zip from the product page.
  2. In WordPress: Plugins → Add New → Upload Plugin.
  3. Choose the ZIP, click Install Now, then Activate.

Pro

The Pro ZIP bundles both Lite and Pro, so installing it brings everything. Activate both plugins, then create saved feeds under Settings → SimpleTube Feed Pro.

Requirements: WordPress 5.8+, PHP 7.4+.

Configuration

Lite — go to Settings → SimpleTube Feed: set your channel ID, display limit, layout (grid/list), whether to show title/date, and cache duration.

Pro — go to Settings → SimpleTube Feed Pro and add feeds. Each feed has its own type (channel/playlist), ID, layout, limit, metadata, and optional custom CSS. You can import/export all feeds as JSON.

Shortcode usage

# Lite — one channel feed
[simpletube_feed channel="UCX_your_channel_ID" limit="6"]

# Pro — a saved feed
[simpletube_feed_pro feed="my-videos" layout="carousel" limit="8"]

Gutenberg block

Search for “SimpleTube” in the block inserter. Set the channel (Lite) or choose a saved feed (Pro), then configure layout and metadata in the sidebar. It renders server-side with the same sanitization and escaping as the shortcode.

RSS mode

Lite (and Pro channel/playlist feeds) use YouTube’s official public RSS feed — no API key required:

https://www.youtube.com/feeds/videos.xml?channel_id=UCxxxxxxxxxxxxxxxxxxxxxx

No scraping, no cost, no quotas. This is the recommended mode for channels.

API mode (Pro)

Pro can use the YouTube Data API v3 for features RSS can’t support reliably — mainly Shorts. API mode is off by default. You supply your own API key; it’s stored in a WordPress option and never sent to any SimpleTube server. Responses are cached to save quota.

Creating a YouTube API key

  1. Open the Google Cloud Console.
  2. Create or select a project.
  3. APIs & Services → Library → enable YouTube Data API v3.
  4. APIs & Services → Credentials → Create credentials → API key.
  5. Paste the key into Settings → SimpleTube Feed Pro → API key.
  6. Restrict the key to the YouTube Data API v3 and your site (referrer/IP).

API quota

The default quota is 10,000 units/day; a list call costs ~100 units. With caching this is a handful of requests per cache window — well within quota. If quota is exhausted, the plugin keeps serving the last cached feed and shows a clear admin error; it never breaks the page.

Caching

Feeds are cached with WordPress transients (default 1 hour; configurable per feed in Pro). The YouTube request happens once per cache window. Use Clear cache in Settings to force a refetch after updates.

Security & privacy

No analytics, no tracking, no cookies, no external accounts. Data is fetched directly from YouTube by your server and never sent to any SimpleTube server. All output is escaped, admin input is sanitized, and privileged actions require capability + nonce checks. Feed XML is parsed with XXE disabled. API keys are never exposed to frontend JavaScript.
