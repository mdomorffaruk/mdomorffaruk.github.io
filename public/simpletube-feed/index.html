Quick start

Install the plugin, add a channel ID or saved feed, and drop the block or shortcode into a post.

1. Install

# Upload this folder to wp-content/plugins, then activate.
wp-content/plugins/simpletube-feed/

2. Get your channel ID

Your channel ID is a 24-character string like UCX_your_channel_ID (find it under “About” on your YouTube channel, or in the channel URL).

3. Add the shortcode

# Lite — one channel feed
[simpletube_feed channel="UCX_your_channel_ID" limit="6"]

# Pro — a saved feed (defined in Settings → SimpleTube Feed Pro)
[simpletube_feed_pro feed="my-videos"]

Or use the SimpleTube Feed block in the Gutenberg editor — no code needed.

FAQ

Is Pro a subscription?

No. It’s a one-time $7 purchase that bundles the Lite plugin too. That price includes future updates for this version track.

Does Lite gather analytics or send data anywhere?

No. Neither plugin adds analytics, cookies, or calls to any SimpleTube server. They fetch YouTube’s own public RSS (and only call the YouTube Data API if you supply your own key) directly from your server.

Do I need a YouTube Data API key?

Not for the basics. Channel and playlist feeds use YouTube’s public RSS with no key. A key is only required for API-powered features in Pro, such as Shorts feeds.

Will it slow my site down?

No. Feeds are cached with WordPress transients, so the heavy YouTube network call happens once per cache window, not on every page view.

Can I style the output to match my theme?

Yes. In Pro, each feed can carry its own custom CSS, and all markup uses clear, classed hooks that are easy to target.
